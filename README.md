# 🌻 Flores Amarillas — 21 de septiembre

Página web romántica hecha con HTML, CSS y JavaScript puro para publicar gratuitamente en GitHub Pages.

## 📁 Estructura

```text
flores_amarillas/
├── index.html
├── style.css
├── script.js
├── images/
│   └── recuerdo.jpg   ← coloca aquí tu foto
└── music/
```

## 🚀 Subir a GitHub

1. Crea un repositorio nuevo en GitHub.
2. Puedes llamarlo `flores-amarillas` o el nombre que quieras.
3. Sube `index.html`, `style.css`, `script.js` y las carpetas `images` y `music`.
4. En GitHub entra a **Settings → Pages**.
5. En **Build and deployment**, selecciona:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/ (root)**
6. Guarda y espera unos minutos.
7. GitHub te dará el enlace de tu página.

## 📸 Cambiar la foto

Coloca una imagen dentro de `images` y llámala exactamente:

`recuerdo.jpg`

También puedes cambiar el texto directamente en `index.html`.

## 🎵 Agregar música

Si quieres música, coloca un archivo MP3 en `music/` y luego podemos añadir un reproductor con botón de reproducción.

## 💛 Personalización

Puedes cambiar:
- nombre de la persona
- carta
- foto
- colores
- frases
- canción
- animaciones

La página funciona sin servidor y es compatible con GitHub Pages.
